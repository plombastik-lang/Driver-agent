# Driver Agent v6.8

## Что исправлено
- Профиль стоимости и P&L в карточке синхронизированы по месяцам. Добавленный месяц сразу появляется в распределении P&L, а изменение общей стоимости перераспределяет статьи с сохранением текущих долей.
- Редактирование статей P&L стало полноценным: у каждой статьи есть активный выпадающий список и кнопка удаления; можно добавлять несколько статей.
- Изменение сумм по статьям P&L пересчитывает общий эффект месяца и профиль драйвера.
- У каждого ручного месяца появилась кнопка удаления.
- Пустые месяцы нельзя сохранить — их надо заполнить или удалить.
- Нельзя сохранить или согласовать драйвер с полностью нулевой стоимостью. Нулевой месяц внутри ненулевого профиля допускается.
- Мобильная таблица P&L ужата до ширины экрана: статьи остаются столбцами, справа виден общий эффект.

## Контрольный сценарий
Открой ручной драйвер → добавь месяц → введи стоимость → убедись, что тот же месяц и сумма появились в P&L. Добавь вторую статью, выбери её из списка и отредактируй распределение. Затем удали лишний месяц.
