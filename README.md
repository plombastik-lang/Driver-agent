# Driver Agent v2.2

Версия с переработанной карточкой драйвера и справочниками.

## Что изменилось
- Карточка драйвера открывается отдельным экраном только из Реестра.
- Мобильная форма редактирования сгруппирована по разделам.
- Справочники отображаются таблицами.
- Убраны внутренние названия систем и продуктов из интерфейса.
- Все файлы по-прежнему лежат в одной папке для удобной загрузки с iPhone.

Загрузи все файлы из архива в корень GitHub-репозитория с заменой старых.
