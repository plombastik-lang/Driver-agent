# Driver Agent v3.7

Изменения версии:

- В кредитной модели для M1 эффект рассчитывается на 50% объёма выдачи — как на средний остаток первого месяца. Со второго месяца применяется полный остаток после погашения.
- Для модельных кредитных драйверов тип эффекта «Доходы» определяется автоматически и больше не запрашивается у пользователя.
- Выбор кнопок в диалоге теперь сохраняется как реплика пользователя. В частности, «Создать новый драйвер» после просмотра похожих записей больше не исчезает из истории.
- В «Справочниках» появился реестр «Модели расчёта»: модель «Кредиты» связана с показателями «Объём выдач» и «Количество выдач» и показывает необходимые параметры.
- «Объём выдач»: маржа, уровень риска, уровень погашения.
- «Количество выдач»: те же параметры плюс средний чек.
- Исправлены два технических дубля предыдущей версии: повтор вопроса агента и двойное сохранение драйвера.
