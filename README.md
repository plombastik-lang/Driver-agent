# Driver Agent v3.6

Главное изменение — разделение базы расчёта, логики и результата расчёта стоимости.

- Для кредитных драйверов «Количество выдач» и «Объём выдач» агент предлагает готовую модель дохода от кредитной выдачи.
- Модель собирает маржу, риск, погашение, горизонт и средний чек (для количества выдач), после чего сама строит помесячный профиль.
- Для драйверов без готовой модели можно описать правило обычным языком или ввести профиль вручную.
- Бизнес-смысл и логика расчёта сохраняются в карточке отдельно от рассчитанных значений.
- Помесячный профиль в карточке редактируется по отдельным месяцам, а не строкой через точку с запятой.
- Длинные ряды больше не выводятся целиком в чат: показываются логика, первые месяцы и итог.
- Поле «База стоимости» переименовано в «База расчёта», чтобы не смешивать базу и финансовый эффект.
