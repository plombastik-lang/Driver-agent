# Driver Agent PWA — v2

Прототип агента управления драйверами для iPhone.

## Что нового в v2
- пошаговый диалог создания драйвера;
- распознавание показателя и продукта из запроса;
- проверка точных дублей и похожих записей;
- уточнение типа эффекта;
- ввод базы и стоимости (например, `1000 бонусов = 20 рублей`);
- дата начала эффекта;
- предпросмотр карточки перед созданием;
- реестр с поиском;
- просмотр, редактирование, смена статуса и удаление драйвера;
- тестовые справочники показателей и продуктов;
- сохранение данных локально на iPhone;
- offline cache v2.

Для обновления GitHub Pages замените `index.html`, `app.js`, `styles.css`, `sw.js` и при желании README.md. Иконки и manifest можно оставить от v1.
