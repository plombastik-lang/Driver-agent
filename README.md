# Driver Agent v3.3

Обновление интерфейса проверки соединения.

- Убрано техническое описание LLM, модели и API из пользовательского интерфейса.
- В «Справочниках» оставлена компактная «Проверка соединения» с кнопкой «Проверить».
- Успешная проверка показывает «Соединение работает».
- При ошибке пользователь видит нейтральное сообщение без технических деталей.
- Остальная логика Driver Agent сохранена без изменений относительно v3.2.

## Обновление GitHub Pages

Замените все 9 файлов в корне репозитория содержимым архива. После обновления в приложении должна отображаться версия v3.3.
