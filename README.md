# Driver Agent v3.2

Прототип агента управления драйверами.

## Что нового
- LLM теперь вызывается через общий Cloudflare Worker: `https://driver-agent-api.plombastik.workers.dev`.
- OpenRouter API key больше не хранится в браузере и не нужен коллегам.
- В разделе «Справочники» можно проверить соединение с общей LLM.
- Остальная логика v3.1 сохранена.

## Публикация
Замените все 9 файлов в корне GitHub Pages репозитория. После обновления в приложении должна отображаться версия v3.2.
