# Driver Agent PWA

Мобильный PWA-прототип агента управления драйверами.

## Что умеет
- диалоговый запрос на создание драйвера;
- извлечение показателя, продукта и типа эффекта из нескольких демо-сценариев;
- проверка точного дубля по паре показатель + продукт;
- автоматическое добавление черновика в реестр;
- локальное сохранение реестра и истории диалога;
- установка на экран «Домой» на iPhone после публикации по HTTPS;
- офлайн-запуск после первого открытия благодаря Service Worker.

## Важно для iPhone
PWA должна быть открыта по HTTPS. После публикации откройте ссылку в Safari → «Поделиться» → «На экран Домой».

## Это прототип
В текущей версии нет подключения к LLM, Final или ЕКП. Разбор запроса работает локально по демо-правилам. Архитектура позволяет позже заменить функцию normalizeRequest() вызовом API агента.
