# Driver Agent v2.1

Версия для обновления с iPhone.

Все файлы лежат в одной папке — папку `icons` создавать больше не нужно.

## Что проверить
После обновления в правом нижнем углу приложения должна быть маленькая надпись `v2.1`.

Тестовый сценарий:
1. Напишите: `Создай драйвер количества выдач по ипотеке`
2. Агент должен спросить тип эффекта.
3. Затем — базу и стоимость.
4. Затем — дату начала эффекта.
5. После этого показать карточку и кнопку `Создать`.

Если сразу появляется драйвер без вопросов, на iPhone открыта старая закэшированная версия.
