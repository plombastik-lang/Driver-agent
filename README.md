# Driver Agent v3.8

Основные изменения версии:

- Обновлён справочник продуктов: Ипотека, Потребительский кредит, Автокредит, Образовательный кредит, Дебетовые карты, Кредитные карты, Платежи, Переводы, ОСАГО, КАСКО, Накопительные счета, Срочные счета.
- Добавлен контроль уникальности драйвера по комбинации: показатель + продукт + канал + сегмент. Точный дубль создать нельзя; для нового драйвера нужно изменить аналитику.
- Для найденного точного драйвера можно открыть существующую карточку или перейти к изменению стоимости.
- Статья P&L не может быть показателем драйвера. Агент просит указать бизнес-показатель, который формирует финансовый эффект.
- В карточку драйвера добавлено распределение эффекта по статьям P&L. Итоговый эффект формируется как сумма статей по каждому месяцу.
- Кредитная модель теперь раскладывает эффект на две статьи: «Чистый процентный доход» и «Расходы на резервы».
- Маржа и уровень риска вводятся в годовом выражении. Система календаризует их по числу дней месяца / дней года. В M1 используется 50% новой выдачи как средний остаток.
- Для количества выдач кредитная модель дополнительно использует средний чек.
- Добавлена модель «Страхование»: «Объём сборов» → коэффициент перевода сборов в ОД → «Операционные доходы».
- В реестре моделей теперь видны бизнес-логика, связанные продукты, показатели, параметры и статьи P&L.
- Способы расчёта: «По готовой модели», «По заданному правилу», «Ручной ввод». Отдельного способа «Одно значение» больше нет: одно значение является частным случаем ручного профиля.
- Добавлен признак применения годового инкремента. Пользователь всегда задаёт инкремент отдельно на каждый год; для процентных/средних показателей агент предлагает ступенчатое действие, для объёмных — распределение годового значения по месяцам.
- Для ступенчатого драйвера в первом году новое значение действует с месяца начала эффекта до декабря, в следующих годах — с января по декабрь. Инкременты разных лет не накапливаются.

Пароль в эту версию намеренно не добавлялся — сначала зафиксирована бизнес-логика.
