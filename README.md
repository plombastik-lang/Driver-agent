# Driver Agent v2.7

Изменения:
- продукт создаваемого драйвера обязан существовать в справочнике продуктов; неизвестный продукт завершает процесс;
- в строке реестра стоимость показывается вместе с базой и единицей измерения, например «5 ₽ за 1 шт.»;
- в раскрытой строке убрано дублирование базы стоимости;
- канал и сегмент всегда отображаются в деталях, даже если не заполнены;
- даты в реестре не выводятся;
- единица измерения показывается один раз как единый атрибут показателя/базы.
