# Driver Agent v2.5

Мобильный PWA-прототип агента управления драйверами.

## Что нового
- подключение OpenRouter прямо из интерфейса;
- API key хранится только в localStorage текущего браузера и не входит в файлы GitHub;
- используется бесплатный роутер `openrouter/free`;
- LLM разбирает свободный текст в структуру драйвера, а проверки реестра и обязательных полей остаются в приложении;
- при ошибке LLM приложение автоматически возвращается к локальным правилам.

## Как подключить LLM
1. Открой вкладку **Справочники**.
2. В блоке **LLM** вставь OpenRouter API key.
3. Нажми **Подключить LLM**.
4. Нажми **Проверить** — должно появиться сообщение «LLM отвечает».
5. Перейди во вкладку **Агент** и напиши запрос обычным языком.

> Это схема только для личного прототипа. Ключ доступен JavaScript-коду страницы и хранится на устройстве. Для промышленного решения нужен серверный backend.
